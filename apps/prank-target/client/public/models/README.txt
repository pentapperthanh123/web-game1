# Custom 3D Character Model Dropzone

Place your Blender/GLTF character model here as:
`character.glb`

Features automatically supported by Prank Target 3D:
1. Full Mesh / Armature hierarchy rendering.
2. Morph Targets (blendshapes) auto-mapped with smooth interpolation (lerp):
   - `angry` (or `furious`): Eyebrows slant & face scowls when rage rises
   - `squint` (or `closeTight`): Eyes squeeze shut tight when hit by projectiles
   - `shock`: Mouth/jaw drops in disbelief
   - `puffed`: Nose or cheeks inflate
3. If no `character.glb` is placed, the game automatically runs the built-in Procedural Stylized 3D Character out-of-the-box!
